# LaTeX 项目管理器

一个 Windows 优先、完全在本机运行的 LaTeX 项目管理软件。它把分散在不同目录中的项目集中成类似 Overleaf“所有项目”的列表，但不接管源码编辑、PDF 阅读或正式编译。

桌面端用于整理项目；写作、编译和调试继续交给 VS Code、LaTeX Workshop 或其他外部工具。仓库同时包含一个只读的 Android 客户端，用于管理并查看多个 GitHub 项目。

## 桌面端

### 项目库

- 单击项目行进行选择，双击打开 Windows 文件夹；“项目详情”和“在 VS Code 中打开”是独立动作。
- 搜索、标签、收藏、最近使用、归档和项目库回收站。
- 按名称、最近使用、大小或同步状态排序，并筛选路径失效、同步异常和缺少主 PDF 的项目。
- 宽屏选择项目后显示快速检查器，窄窗口显示底部面板；支持舒适/紧凑密度。
- 从本机文件夹批量导入多个项目，自动标记重复路径；也可以从模板创建项目。
- 复制完整项目、导出源码 ZIP、打开或导出最新 PDF。
- 显示每个项目的内容大小和文件数量。
- 显示 GitHub 状态：`排队中`、`同步中`、`等待重试`、`安全阻止`、`已同步`和`同步失败`。
- 项目列表保持紧凑；次要操作收在更多菜单中。

项目库回收站只隐藏本机索引记录，不会删除磁盘上的整个项目目录。

### 项目管理页

管理页固定为四个标签：

1. **项目介绍**：主文件、文档目标、当前方案、最新 PDF、移动端主 PDF 和打开文件夹/VS Code 的入口。
2. **文件**：浏览、搜索、新建、导入、复制、重命名、移动、回收站、系统打开和定位；不提供源码编辑。
3. **研究资料**：按文档目标组织论文、书籍、数据与补充材料，管理多个附件版本、关系角色和移动端可用性。
4. **同步**：连接远端仓库、查看同步状态并控制自动同步。

重命名或移动被 `\input`、`\include`、`\includegraphics`、`\bibliography`、`\addbibresource` 等字面量引用的文件时，客户端先展示完整影响和哈希校验；只有确认后才保留原编码、BOM 与换行并更新可确定引用，同时创建可撤销快照。界面不提供源码编辑器、内嵌 PDF 或 LaTeX 配置面板。

### 清理临时文件

每个项目都有“清理临时文件”操作。清理分为两步：

1. 只读扫描并列出文件数、预计释放空间、类型和示例路径。
2. 用户再次确认后，仅删除预览中且没有发生变化的临时文件。

可清理内容包括 `.aux`、`.log`、`.toc`、`.synctex.gz` 等 LaTeX 辅助文件，以及项目管理器自己的 build/runtime 缓存。它明确保留：

- `.tex`、`.bib`、`.cls`、`.sty` 等源文件；
- 所有 PDF；
- `references` 原始文稿；
- `.git`、快照和项目库回收站；
- 扫描后新增或发生变化的文件。

临时文件清理属于永久删除，因此界面始终先展示预览，不会静默执行。

### GitHub 自动同步

- “设置”页可通过 GitHub CLI 打开官方浏览器登录；密码和令牌由 GitHub/Git Credential Manager 管理，本软件不保存。
- 导入项目时会询问是否启用同步；选择后自动创建公开或私有仓库、连接并完成首次推送。
- 已导入项目也可以在 GitHub 页一键建仓，并随时切换公开/私有（设为公开前会再次确认）。
- 每个项目单独连接远端仓库，自动同步可单独开启或暂停；项目页显示实际仓库地址。
- 项目停止变化约 10 秒后，将新增、修改和删除合并成一次提交并推送。
- 关闭主窗口后默认缩到 Windows 托盘继续同步；托盘菜单可以同步全部、暂停/恢复或彻底退出，不默认开机启动。
- 每个项目同一时间只执行一个同步任务，全局最多并行两个项目；断网后按 30 秒、2 分钟、5 分钟重试。
- 推送前先获取远端状态。只有工作区干净、没有本机待推送提交且可以安全快进时，才自动执行 `pull --ff-only`；分叉或冲突不会自动合并、变基或强推。
- 提交前扫描私钥、高置信令牌、`.env`、凭据文件和未使用 Git LFS 的大文件；密钥直接阻止，普通风险必须明确确认。
- 每个项目保留最近 100 条同步记录；成功保持安静，安全阻止或最终失败通过系统通知提示。
- 也支持手动粘贴已有 HTTPS/SSH 仓库地址。
- 若 Git 尚未配置作者信息，可直接在同步页填写“提交姓名/提交邮箱”；信息只写入当前项目的本地 Git 配置。
- 不会强制推送。远端领先、历史分叉、认证失败或网络失败时进入“同步失败”，等待用户处理。
- 私有仓库中的项目资料可按设置同步；大文件请按需使用 Git LFS。
- 公开仓库中的新资料默认保持“仅本机”。只有逐份确认版权风险后才能进入候选提交；切换公开前还会检查 Git 历史中的受限资料。

### 研究资料工作台（1.0）

- `ResearchWork → 项目资料 → 附件 → 文档目标关联` 将“物理文件”和“研究关系”分开管理，同一资料可以关联多个文档目标并分别指定角色和首选附件。
- 默认仍把允许同步的附件复制到项目 `references/`，保持普通文件夹、Git 与 Android 工作流兼容；仅本机附件不会写入可携带路径。
- 旧 `references/` 只读扫描后进入“待整理”，不会擅自移动、改名或猜测目标。
- SHA-256 相同只用于本机识别重复作品，绝不自动删除项目副本；DOI/arXiv 相同可作为不同版本归入同一作品。
- `.latex-project.json` v3 只携带项目局部资料 ID、书目信息、目标关系和允许同步的相对附件路径；私人笔记、评分、绝对路径及跨项目作品 ID 始终只留在本机。
- 项目快照同时保护源码与仅本机资料，恢复永远写入新目录；构建缓存、Git 对象和撤销目录不会进入快照。

### 移动端主 PDF

- 项目介绍页可以为每个文档目标指定一个成品 PDF，并选出项目默认成品。
- 保存后在项目根目录创建 `.latex-project.json`。它只包含项目 ID、显示名称、目标、方案和项目内相对 PDF 路径，不包含本机绝对路径、账号或令牌。
- PDF 必须实际位于项目目录内并进入 GitHub 同步范围；`references`、临时构建目录和项目外路径不会成为自动候选。
- 旧项目不会被强制创建该文件；只有用户保存移动端设置后才生成。

### 首次使用向导

首次使用会依次检查 Git、Git LFS、GitHub CLI/登录、VS Code、LaTeX Workshop 和 TeX 工具链，再引导导入项目。已有项目升级时只显示可关闭提示，也可以从设置重新打开向导。

### 客户端自动更新

- “设置”页可以分别控制启动时自动检查、发现版本后自动下载、关闭窗口后进入托盘以及全局暂停同步。
- 源码仓库已经公开；更新检查读取公开的 GitHub Release，不会把访问令牌写入客户端。
- 自动更新只接受 Ed25519 签名的 `release-manifest.json`，并固定校验资产名、大小、SHA-256 与签名证书摘要；缺少签名或摘要时拒绝安装。
- Windows 安装版按当前用户安装，不要求管理员权限；这是推荐版本。
- 便携版继续提供，但 Electron 官方不支持便携版安全地自行覆盖，因此便携版只能打开已下载的安装包完成迁移。

## Android 只读客户端

源码位于 [`android-viewer`](android-viewer)。它使用 Jetpack Compose 构建，采用内容优先的 Liquid Glass 设计：玻璃只用于浮动导航、PDF 工具栏和下载反馈，项目与文件内容保持清晰；Android 12 及以上使用真实背景模糊，旧设备或低内存设备自动降级为高对比霜化材质，并跟随系统浅色/深色主题：

- 把多个 GitHub 公开或私有仓库持久保存在手机项目库中，并可随时添加、切换或移除本机入口；
- 首页按“继续阅读 → 发现新版本 → 离线资料 → 最近主 PDF”排列；移动索引缺失或损坏时不会清空已缓存项目或资料；
- 浏览目录与默认分支；
- 使用内置代码查看器阅读 `.tex`、`.bib`、`.cls`、`.sty`、Markdown 和常见文本文件；
- 使用 PDFium 分块渲染器连续阅读 PDF，支持双指缩放、双击适宽、目录、跳页、本地书签、旋转保持位置和沉浸式工具栏；
- 记录每个仓库和 PDF 的阅读页码；PDF 更新后自动把页码限制在新版有效范围内；
- 存储分为临时阅读缓存、明确保留的离线资料和导出到 `Download/LaTeX项目` 的下载文件；临时缓存采用 512 MB LRU，离线保留不会被自动清理；
- 搜索仓库和当前目录；
- 每个文件都可以单独下载，每个仓库也可以整体下载为 ZIP；
- 普通下载默认保存到 `内部存储/Download/LaTeX项目`，完成后用可关闭横幅显示准确位置并提供“打开”；
- Android 下载使用带常驻通知的持久后台任务；熄屏、切换应用和短时断网不会丢失进度，下载历史会在重启后恢复；
- 下载支持断点续传、相同任务去重和 GitHub Media/Raw/API 备用源切换；进度面板可隐藏，完整状态仍保留在下载页与系统通知中；
- 下载中心统一记录项目 ZIP、PDF、源码、普通文件和 APK，最多保留 200 条，并按类型筛选；
- 每条下载记录可以打开、查看来源与保存位置，或通过 Android 系统分享面板发送到微信、WPS、网盘等应用；
- 移除或清空下载历史只清理记录，不会删除手机中的实际文件；文件被外部移动或缓存清理后会明确标记为不可用；
- PDF 下载完成后先做格式校验和本地随机访问缓存，再交给内置查看器，避免下载不完整或 Content URI 不兼容导致打开失败；
- PDF 单页渲染受内存上限保护；不兼容页面不会导致整个应用退出，并可重新下载或交给其他 PDF 应用打开；
- 自动检查 Android 新版本，也可以自动下载 APK，校验后由 Android 系统确认安装；
- 没有编辑、提交、上传或删除功能；
- 仓库快照、移动索引、阅读进度、书签、缓存和下载任务保存在 Room；升级时迁移旧数据，断网不会清空项目。
- Android 只读取 schema v3 中允许同步的研究附件；仅本机资料显示“仅电脑可用”，不会伪装为可下载。
- 私有仓库优先使用 GitHub Device Flow 浏览器授权；PAT 仅作为高级入口，并由 Android Keystore 加密保存。

安卓构建和权限说明见 [`android-viewer/README.md`](android-viewer/README.md)。

## 本地数据与安全

- 导入项目只登记绝对路径，不复制、不接管也不改写 `.tex`。
- 标签、收藏、归档、最近使用和 GitHub 状态保存在本机 SQLite 索引中。
- 项目大小只统计实际内容，跳过 `.git` 与项目管理器自身的构建缓存。
- 文件夹、ZIP/PDF 保存位置通过 Electron 原生对话框选择。
- 所有外部程序都通过参数数组启动，不经过 shell 字符串拼接。
- 不创建或覆盖项目中的 `.vscode/settings.json`。
- 不提供自建账号、云端协作或遥测；可选的 GitHub 登录由官方 GitHub CLI 完成。

本机索引默认位于：

```text
%APPDATA%\latex-workbench\library.sqlite
```

## 开发与测试

桌面端需要 Node.js 24 与 pnpm 11：

```powershell
pnpm install
pnpm dev
```

质量检查和 Windows 安装版/便携版：

```powershell
pnpm typecheck
pnpm test
pnpm test:e2e
pnpm build
pnpm package:portable
pnpm package:windows
```

Windows 安装版和便携版都包含 Electron 运行时，不捆绑 TeX Live，也不会把项目文件复制到应用目录。带 `Setup` 的文件是支持后续自动更新的推荐安装包。

### 1.0 Beta 并行安装

`1.0.0-beta.1` 使用独立的 Windows 应用 ID、产品名、安装目录和用户数据目录，可以与当前 `0.11.1` 正式版同时安装。Beta 的安装包和便携版输出到 `dist-beta`，文件名明确包含 `Beta`，不会覆盖 `dist` 中的正式版资产：

```powershell
pnpm package:windows:beta
```

GitHub Actions 的 Windows、Android 和联合发布工作流都要求显式选择 `stable` 或 `beta`。`v1.0.0-beta.4` 标签只会创建 GitHub Pre-release；正式标签仍创建 Latest Release。Beta 与正式版使用不同的工作流产物名和附件名，避免相互覆盖。
